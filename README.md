# Time Capsule DAO — MVP

A time-locked ETH vault. Lock ETH now, beneficiary claims after the unlock date.

**Not a will. Not legal advice. Not financial advice.**

## Setup

```bash
npm run install:all
```

## Run Tests

```bash
npm run test
```

## Start Local Node

```bash
npm run node
```

## Deploy

```bash
# Mumbai testnet
npm run deploy:mumbai

# Polygon mainnet (requires real funds)
npm run deploy:polygon
```

## Frontend

```bash
npm run dev:frontend
```

Then open http://localhost:5173
